**提供内容:** 日本語リソース（`ja-JP`）および一部の変更済みアプリケーションファイル

## 概要

dnSpyEx は、.NET アセンブリの閲覧、逆コンパイル、解析、デバッグなどに利用できるツールです。本パッチは、その画面やメニュー、各種表示項目を日本語で扱いやすくするための**非公式日本語ローカライズ**です。

メニューや PE ヘッダーの表示など、日本語化された画面の一例を確認しています。ただし、全機能・すべての画面について翻訳の完全性や正常動作を保証するものではありません。

## 日本語化の画面例

日本語化後の画面では、たとえば次のような表示が確認できます。

- メニュー: `ファイル`、`編集`、`表示`、`デバッグ`、`ウィンドウ`、`ヘルプ`
- 左ペイン: `アセンブリ エクスプローラー`
- PE 解析画面: `DOS ヘッダー`、`ファイル ヘッダー`、`オプショナル ヘッダー`、`セクション`

## ダウンロード

既存の dnSpyEx が使用する実行環境に合わせて、**いずれか一方**を選択してください。

| 対象環境 | ダウンロード | サイズ |
| --- | --- | ---: |
| .NET Framework 4.8 | [net48.rar](net48.rar) | 3,467,015 バイト |
| .NET 10 | [net10.rar](net10.rar) | 3,454,662 バイト |

`net48.rar` には `dnSpy.exe` と `dnSpy.Console.exe` が含まれています。一方、`net10.rar` にはこれらの EXE は含まれていません。どちらのパッケージにも `ja-JP` リソースおよび一部のアプリケーション DLL が含まれています。**単なる言語リソースのみのパッチではありません。**

### チェックサム

ダウンロードしたファイルの同一性を確認するため、以下の値を使用してください。値は配布用 RAR ファイルそのものから算出したものです。

**net48.rar**

| アルゴリズム | ハッシュ値 |
| --- | --- |
| MD5 | `c7c416ed3d4de589b0dda87ffaa42268` |
| SHA-1 | `032fb42f9067e4fc3cd2f73eebda61ae12730a5a` |
| SHA-256 | `dbabdea49ef326b68f880354ef4e3ded593d9cbabdaf77680d9807f6dfbd8272` |

**net10.rar**

| アルゴリズム | ハッシュ値 |
| --- | --- |
| MD5 | `fd0d6d19f7b54e8abe6182c46ffcd57c` |
| SHA-1 | `b289e9e836f490363349dc3c4972247e49b42ade` |
| SHA-256 | `7fb11bf86042fb28b44eb214f9c963dc54a0565447b1a3460bfe1ddbfa12b7e6` |

PowerShell で SHA-256 を確認する例:

```powershell
Get-FileHash -Algorithm SHA256 .\net48.rar
Get-FileHash -Algorithm SHA256 .\net10.rar
```

※ ハッシュ値の一致はファイルの同一性を示しますが、完全な安全性や機能検証を意味しません。

## 導入方法

1. ご利用中の dnSpyEx のバージョン（6.6.0）と実行環境（.NET Framework 4.8 / .NET 10）を確認します。
2. dnSpyEx を終了し、**インストール先のフォルダーを丸ごとバックアップ**します。
3. 対象環境に合った RAR ファイルをダウンロードし、7-Zip などの対応ツールで展開します。
4. 展開後の `net48` または `net10` フォルダーの**中身**を、元の dnSpyEx 配布物の対応する場所へコピーします。フォルダー階層を確認し、`bin/ja-JP/` が正しい場所になるようにしてください。
5. 同名 DLL や EXE の上書きが必要な場合があります。対象を確認したうえでコピーし、dnSpyEx を起動して日本語表示を確認します。

**重要:** `net48` と `net10` の DLL を混在させないでください。異なるバージョンの dnSpyEx に適用しないでください。起動しない場合はバックアップから元に戻してください。

## 既知の制限と注意事項

- すべての UI、プラグイン、ダイアログの翻訳・表示を網羅しているとは限りません。
- 表示の崩れ、翻訳漏れ、機能上の不具合が発生する可能性があります。
- パッチにはプログラム本体の DLL などが含まれているため、適用前のバックアップを推奨します。
- このリポジトリは dnSpyEx の公式サポート窓口ではありません。

不具合を報告する際は、使用した RAR ファイル、Windows のバージョン、対象のランタイム、再現手順、必要に応じてスクリーンショットを添えてください。
